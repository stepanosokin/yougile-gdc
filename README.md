# YouGile для ИИ-агентов

Откройте этот репозиторий в своём агенте, войдите в YouGile и попросите: «Покажи мои задачи» или «Запиши 45 минут в задачу …». Клиенты подключаются напрямую к [официальному MCP YouGile](https://ru.yougile.com/data/ai/mcp/setup.md). Для просмотра задач достаточно MCP; для учёта времени нужен также Node.js 18+ на машине агента.

## Первое подключение

Из корня **доверенного проекта** откройте клиент и авторизуйтесь в нужной компании. Для сводок достаточно чтения, для записи часов нужен также доступ к отправке сообщений в чат задачи. Конфигурации в репозитории содержат только публичный адрес; OAuth выполняется отдельно в каждом клиенте.

| Клиент | Проектный файл | Где войти |
| --- | --- | --- |
| Codex CLI / IDE | `.codex/config.toml` | В корне проекта: `codex mcp list`, затем `codex mcp login yougile`. Codex загружает конфигурацию доверенных проектов. |
| OpenCode | `opencode.json` | `/mcps` → `yougile` → вход. |
| Claude Code | `.mcp.json` | Подтвердите проектный сервер и в `/mcp` выберите `yougile` для входа. |
| Cursor | `.cursor/mcp.json` | В настройках MCP включите `yougile` и пройдите авторизацию. |
| VS Code с агентом Copilot | `.vscode/mcp.json` | В палитре команд: `MCP: List Servers` → `yougile` → запуск и авторизация. |

**Проверка без записи:** попросите «Через YouGile вызови `get_project_tree` с `id=null`, `cursor=null`, `projectState=active` и покажи названия проектов первой страницы». Пустой успешный ответ означает, что нет видимых активных проектов; при ошибке входа или прав проверьте компанию и разрешения подключения.

## Учёт времени

В репозитории есть переносимый навык **`yougile-worklog`**. Например:

- «Запиши 1,5 часа в задачу `<ID или ссылка>` за сегодня».
- «Начал задачу `<ID>`» → «Перерыв» → «Продолжил» → «Закончил, запиши время».
- «Покажи состояние таймера» или «Отмени таймер без записи».

В Codex навык можно вызвать как `$yougile-worklog`, в OpenCode — `@yougile-worklog`, в Claude Code — `/yougile-worklog`. В клиенте без автоматического обнаружения скажите: «Следуй `.agents/skills/yougile-worklog/SKILL.md`». Клиенту нужны доступ к shell и к этому репозиторию. Для подключения MCP без навыка shell не требуется.

Таймер локальный: запускать фоновый процесс не нужно. После закрытия агента интервал продолжается до паузы или остановки. При записи агент отправляет в **чат задачи** дату и длительность; это не поле «Факт» и не штатный табель. Автор определяется учётной записью MCP. При неопределённой доставке агент проверяет чат по уникальному маркеру записи, прежде чем предлагать повтор.

Состояние хранится вне Git в `~/.yougile-worklog` (переопределение — `YOUGILE_WORKLOG_DIR`). Клиенты одного профиля могут начать и закончить один интервал из разных сессий. Для разных компаний или аккаунтов задайте разные каталоги. Это отдельное хранилище от личного навыка `yougile-time`: начатый там таймер завершайте тем же навыком. Для локальной проверки без обращений к YouGile:

```sh
node .agents/skills/yougile-worklog/time.cjs status
```
