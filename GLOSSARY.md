# Трекинг работы команды

Команда ведёт рабочие задачи и использует сводку для подготовки к планёрке.

## Language

**Рабочая задача**:
Обязательство команды выполнить конкретную работу. Отличается от задачи разработки интеграции, которая описывает изменение самого инструмента трекинга.

**Сводка к планёрке**:
Личная подборка рабочих задач, по которым нужно решение или уточнение. Каждый пункт указывает на карточку и формулирует вопрос для обсуждения.
