# Метки triage

Каноническая роль совпадает с названием метки в GitHub:

| Роль / метка | Когда применять |
| --- | --- |
| `needs-triage` | Задача ждёт оценки сопровождающего. |
| `needs-info` | Нужны сведения от автора. |
| `ready-for-agent` | Постановка полна, агент может выполнить задачу самостоятельно. |
| `ready-for-human` | Реализация требует участия человека. |
| `wontfix` | Принято решение не выполнять задачу. |
