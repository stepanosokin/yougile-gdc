# Доменная документация

Перед изучением кода прочитай корневой `GLOSSARY.md` и относящиеся к задаче
решения из `docs/adr/`. Если их ещё нет, продолжай работу: `domain-modeling`
добавляет записи по мере согласования терминов и решений.

Используй термины словаря в задачах, предложениях, гипотезах и названиях тестов.
Если нужного понятия нет, проверь существующие термины; реальный пробел отметь
для `domain-modeling`. Если предложение противоречит ADR, укажи номер решения
и объясни, почему его стоит пересмотреть.
