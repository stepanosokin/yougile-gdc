## Agent skills

### Учёт времени
Когда пользователь просит записать время в YouGile, начать, приостановить или закончить таймер, следуй `.agents/skills/yougile-worklog/SKILL.md`.

### Issue tracker
Рабочие задачи команды ведём в YouGile, разработку интеграции — в GitHub Issues. См. `docs/agents/issue-tracker.md`.

### Triage labels
Перед разбором задачи сверь роль с меткой в `docs/agents/triage-labels.md`.

### Domain docs
У проекта один словарь и один каталог архитектурных решений. Перед изучением кода прочитай `docs/agents/domain.md`.
